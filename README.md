# Multi-Modal AI System for Early Childhood Health Monitoring and Development Assessment (J26-SE-349)

An integrated, explainable AI platform designed to provide parents and healthcare providers with continuous, localized child health monitoring. The system combines smartphone-based early childhood caries (ECC) screening, personalized vaccine adverse-reaction prediction, longitudinal growth-faltering forecasting with Sri Lankan nutrition guidance, and mental development delay assessment with tailored activity recommendations.
